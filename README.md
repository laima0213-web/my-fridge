# 🧊 은혜네 냉장고

우리 집 먹거리를 한눈에 보는 냉장고 정리 웹앱입니다.

## 쓰는 법

1. 폰 브라우저에서 이 주소를 엽니다.
2. Chrome 메뉴 → **홈 화면에 추가**를 누르면 앱처럼 열립니다.
3. 냉장실·냉동실에 재료를 넣고, 유통기한을 적으면 임박한 것이 위로 올라옵니다.
4. 사야 할 품목을 체크해 두고 한 번에 냉장실·냉동실로 넣을 수 있습니다.
5. 만들 요리에 필요한 재료를 적으면, 지금 있는 재료는 초록색으로 표시됩니다.
6. 식단 캘린더에는 그날 먹은 사진을 날짜별로 모아 둘 수 있습니다.

## 다섯 개 탭

| 탭 | 하는 일 |
| --- | --- |
| 🧊 냉장실 | 재료·유통기한·수량 관리, 임박 알림 |
| ❄️ 냉동실 | 냉장실과 같은 방식, 서로 옮길 수 있음 |
| 🛒 사야 할 품목 | 장보기 목록, 체크 후 냉장·냉동실로 넣기 |
| 🔍 만들 요리 | 필요 재료 자동 매칭, 없는 재료 장보기 담기 |
| 📅 식단 캘린더 | 날짜별 식단 사진(여러 장) 모아 보기 |

## 저장 방식

- 기본은 이 폰에만 저장됩니다(`localStorage`).
- ☁️ **가족 폰과 함께 쓰기**를 켜고 가족 암호를 한 번 넣으면, 가족 폰과 냉장고·장보기·식단 사진이 맞춰집니다.
  - 읽고 쓰는 곳은 Firebase Realtime Database의 `homes/6013b071e038aa90/fridge/eunhye_fridge_v1` 한 곳뿐입니다.
  - 사진은 긴 쪽 720px, JPEG 0.72로 줄여 저장합니다.
- 가족 암호는 코드에 들어 있지 않습니다. 각 폰에서 처음 한 번만 입력하면 기억합니다.

## 파일

- `index.html` — 앱 전체 (화면·기능·동기화)
- `manifest.json` — 홈 화면에 추가할 때 쓰는 설정
- `icon-180.png`, `icon-192.png`, `icon-512.png` — 앱 아이콘
